Chunk Collector is a mod desined to cut down on the need for large hopper collection centers for your farms. By cutting down on the need for so many hoppers you are able to make your world / sevrer run more effectivly.

## Items

- **Chunk Collector:** Acts as a hopper for the whole chunk. You are able to set whitelist items for it to collect. You are able to link it to a chest for an output location.
  
---

## Fetures

- **Whole Chunk Item Collection:** Be able to collect items droped within the whole chunk with one Chunk Collector.
- **Chest Linking:** Link the output chest of the chunk collector to cut down on the use of un needed hoppers in your world / server.
- **Multi Select:** Be able to config multipule chunk collectors to the same chest as a time.

---

## Compatibility

Smart Sorter is designed to work with:
